# 🎓 Student Job Portal

A full-stack web application that helps students find jobs and internships and allows administrators to manage job opportunities and student applications.

## 🚀 Features

### 👨‍🎓 Student Features
- Student Registration
- Student Login
- View Profile
- Browse Available Jobs
- Search Jobs
- Apply for Jobs
- Track Application Status

### 👨‍💼 Admin Features
- Admin Login
- Admin Dashboard
- Add New Jobs
- View Student Applications
- Update Application Status

## 🛠️ Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS
